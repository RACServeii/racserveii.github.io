Generador Presupuestario

Política de privacidad

Última actualización: 16 de octubre de 2026

1. Quiénes somos

Generador Presupuestario (el "programa") es una aplicación de escritorio de RACSERVEI para crear presupuestos e informes para clientes. Esta política explica qué datos usa el programa y cómo los trata.

2. Dónde se guardan tus datos

Todo lo que ingresas (tu perfil, clientes, proveedores, presupuestos, informes y eventos del calendario) se guarda en una base de datos dentro de tu propio computador. RACSERVEI no tiene un servidor que reciba ni almacene esa información.

3. Recuperación de contraseña

Si usas "Recuperar contraseña", el programa envía tu correo electrónico al servicio de correo Resend solo para mandarte un código de verificación. No se usa para ningún otro fin.

4. Respaldo en Google Drive

La conexión con Google Drive es opcional. Si la activas:

  • El programa pide únicamente el permiso https://www.googleapis.com/auth/drive.file, que le permite ver y administrar solo los archivos que él mismo crea en tu Drive.
  • Lo usa para subir copias de respaldo de su base de datos a la carpeta "Respaldos Generador Presupuestario" de tu Google Drive.
  • No puede leer, modificar ni borrar ningún otro archivo de tu Drive.
  • La autorización de Google (token de acceso) se guarda solo en tu computador.

Los datos obtenidos de Google no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustarán a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado (Limited Use).

5. Cómo desconectar y borrar

  • Puedes quitar el acceso del programa a tu cuenta de Google cuando quieras en myaccount.google.com/permissions.
  • Los respaldos son archivos de tu Drive: puedes borrarlos directamente desde Google Drive.
  • Los datos del computador se borran al eliminar la carpeta de datos del programa o desinstalarlo.

6. Cambios a esta política

Si esta política cambia, se publicará aquí la nueva versión con su fecha de actualización.
